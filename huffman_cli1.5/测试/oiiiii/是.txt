与你的 MinGW 编译器无缝衔接：Qt 官方版本完美支持 MinGW。之前为解决兼容性付出的努力没有白费，现在可以直接用。

2. 核心代码实现：mainwindow.cpp
请替换 mainwindow.cpp 文件的内容为以下代码。这段代码包含了我们在 GUI 部分所需的核心逻辑，我将用中文注释为你逐行解释。

cpp
#include "mainwindow.h"
#include "ui_mainwindow.h"
#include "huffman.h" // 包含你的核心压缩库
#include <QFileDialog>
#include <QMessageBox>
#include <QThread>
#include <QDebug>

// --- 1. 工作线程类 ---
// 将耗时的压缩/解压任务移到单独线程，防止界面假死
class CompressWorker : public QObject {
    Q_OBJECT
public:
    // 构造函数，接收任务类型、输入、输出路径
    CompressWorker(bool isCompress, QString in, QString out)
        : m_isCompress(isCompress), m_input(in), m_output(out) {}

public slots:
    // 当线程启动时，此函数会自动执行
    void doWork() {
        bool result = false;
        // 调用你的核心库，并传入进度回调Lambda
        // QThread::currentThread() 确保回调在子线程运行
        auto callback = [this](double progress) {
            // 通过信号槽安全地将进度传回主线程更新UI
            emit progressUpdated(progress);
        };

        if (m_isCompress) {
            // 调用压缩函数，需将 QString 转为 std::filesystem::path
            result = HuffmanLib::CompressFile(m_input.toStdString().c_str(),
                                              m_output.toStdString().c_str(),
                                              callback);
        } else {
            result = HuffmanLib::DecompressFile(m_input.toStdString().c_str(),
                                                m_output.toStdString().c_str(),
                                                callback);
        }
        // 任务完成，发射结果信号
        emit resultReady(result);
    }

signals:
    void progressUpdated(double value);
    void resultReady(bool success);

private:
    bool m_isCompress;
    QString m_input;
    QString m_output;
};

// --- 2. 主窗口类实现 ---
MainWindow::MainWindow(QWidget *parent) :
    QMainWindow(parent),
    ui(new Ui::MainWindow),
    m_workerThread(nullptr) // 初始化线程指针
{
    ui->setupUi(this);

    // 设置进度条范围为0-100
    ui->progressBar->setRange(0, 100);

    // --- 绑定界面信号与槽 ---
    // 2.1 选择文件按钮
    connect(ui->selectFileBtn, &QPushButton::clicked, this, &MainWindow::onSelectFileClicked);
    // 2.2 压缩按钮
    connect(ui->compressBtn, &QPushButton::clicked, this, &MainWindow::onCompressClicked);
    // 2.3 解压按钮
    connect(ui->decompressBtn, &QPushButton::clicked, this, &MainWindow::onDecompressClicked);
}

MainWindow::~MainWindow() {
    // 析构时，等待工作线程安全结束
    if (m_workerThread && m_workerThread->isRunning()) {
        m_workerThread->quit();
        m_workerThread->wait();
    }
    delete m_workerThread;
    delete ui;
}

// 槽函数：点击选择文件
void MainWindow::onSelectFileClicked() {
    // 弹出系统文件对话框
    QString fileName = QFileDialog::getOpenFileName(this, "选择文件", "", "所有文件 (*.*)");
    if (!fileName.isEmpty()) {
        ui->filePathEdit->setText(fileName);
    }
}

// 槽函数：点击压缩按钮
void MainWindow::onCompressClicked() {
    // 获取界面上的文件路径
    QString inputFile = ui->filePathEdit->text();
    if (inputFile.isEmpty()) {
        QMessageBox::warning(this, "提示", "请先选择文件！");
        return;
    }

    // 生成默认输出文件名
    QString outputFile = inputFile + ".huf";
    // 启动后台压缩任务
    startWork(true, inputFile, outputFile);
}

// 槽函数：点击解压按钮
void MainWindow::onDecompressClicked() {
    QString inputFile = ui->filePathEdit->text();
    if (inputFile.isEmpty() || !inputFile.endsWith(".huf")) {
        QMessageBox::warning(this, "提示", "请先选择一个 .huf 压缩文件！");
        return;
    }

    // 生成默认输出文件名
    QString outputFile = inputFile.left(inputFile.lastIndexOf('.'));
    // 启动后台解压任务
    startWork(false, inputFile, outputFile);
}

// 启动后台任务的通用函数
void MainWindow::startWork(bool isCompress, QString inPath, QString outPath) {
    // 禁用按钮，防止重复点击
    ui->compressBtn->setEnabled(false);
    ui->decompressBtn->setEnabled(false);
    ui->selectFileBtn->setEnabled(false);
    ui->progressBar->setValue(0); // 重置进度条

    // 清理旧的线程对象
    if (m_workerThread) {
        if (m_workerThread->isRunning()) {
            m_workerThread->quit();
            m_workerThread->wait();
        }
        delete m_workerThread;
    }

    // 创建新的工作线程和Worker对象
    m_workerThread = new QThread(this);
    CompressWorker *worker = new CompressWorker(isCompress, inPath, outPath);
    worker->moveToThread(m_workerThread);

    // 连接信号槽，建立线程间通信的桥梁
    connect(m_workerThread, &QThread::started, worker, &CompressWorker::doWork);
    connect(worker, &CompressWorker::progressUpdated, this, &MainWindow::updateProgress);
    connect(worker, &CompressWorker::resultReady, this, &MainWindow::handleWorkFinished);

    // 自动清理对象
    connect(worker, &CompressWorker::resultReady, worker, &CompressWorker::deleteLater);
    connect(m_workerThread, &QThread::finished, m_workerThread, &QThread::deleteLater);

    // 启动线程！
    m_workerThread->start();
}

// 更新进度条的槽函数，由工作线程的信号触发
void MainWindow::updateProgress(double value) {
    ui->progressBar->setValue(static_cast<int>(value * 100));
}

// 任务完成后的处理
void MainWindow::handleWorkFinished(bool success) {
    // 重新启用按钮
    ui->compressBtn->setEnabled(true);
    ui->decompressBtn->setEnabled(true);
    ui->selectFileBtn->setEnabled(true);

    if (success) {
        QMessageBox::information(this, "完成", "操作成功完成！");
        ui->progressBar->setValue(100);
    } else {
        QMessageBox::critical(this, "错误", "操作失败，请检查文件！");
        ui->progressBar->setValue(0);
    }
}

4. 解决中文乱码问题
好消息是，Qt 配合 MinGW 编译器，源代码文件只要保存为 UTF-8 编码，一般不会出现中文乱码。如果你在 IDE 中看到乱码，可以试试以下两种解决方法：

方法一：在 main() 函数开头添加两行代码，强制使用 UTF-8 编码。

cpp
#include <QTextCodec>
int main(int argc, char *argv[]) {
    QApplication a(argc, argv);
    QTextCodec::setCodecForLocale(QTextCodec::codecForName("UTF-8"));
    // ... 其余代码
}
方法二：如果方法一无效，可以调整 Qt Creator 的设置：打开 工具 -> 选项 -> 环境 -> Interface，将 Text codec for tools 选项从 UTF-8 改为 System 试试。

创建项目：打开 Qt Creator，点击 File -> New Project，选择 Qt Widgets Application，然后按照向导提示完成项目创建。

添加代码：将上面的 C++ 代码和 CMake 配置粘贴到对应的文件中。

编译并运行：点击左下角绿色的 Run 按钮（或按 Ctrl+R）。Qt Creator 会自动调用 MinGW 编译你的项目。

测试：程序启动后，你应该能看到一个带有按钮、输入框和进度条的窗口。你可以用它来压缩或解压文件，并观察进度条的实时更新。

// ==================== CompressWorker 实现 ====================
CompressWorker::CompressWorker(bool isCompress, QString inPath, QString outPath, QObject *parent)
    : QObject(parent), m_isCompress(isCompress), m_inputPath(inPath), m_outputPath(outPath)
{}

void CompressWorker::doWork()
{
    bool success = false;
    double elapsed = 0.0;
    double ratio = 0.0;
    QString message;

    // 计时开始
    auto start = std::chrono::high_resolution_clock::now();

    // 进度回调：通过信号安全地传回主线程
    auto callback = [this](double progress) {
        emit progressUpdated(progress);
    };

    std::filesystem::path input = m_inputPath.toStdString();
    std::filesystem::path output = m_outputPath.toStdString();

    if (m_isCompress) {
        // 获取原始大小
        uint64_t origSize = 0;
        std::error_code ec;
        if (std::filesystem::exists(input, ec))
            origSize = std::filesystem::file_size(input, ec);

        success = HuffmanLib::CompressFile(input, output, callback);

        if (success) {
            uint64_t compSize = std::filesystem::file_size(output, ec);
            if (origSize > 0)
                ratio = 100.0 * compSize / origSize;
        }
    } else {
        success = HuffmanLib::DecompressFile(input, output, callback);
    }

    auto end = std::chrono::high_resolution_clock::now();
    elapsed = std::chrono::duration<double>(end - start).count();

    if (success)
        message = m_isCompress ? "压缩成功" : "解压成功";
    else
        message = m_isCompress ? "压缩失败" : "解压失败";

    emit resultReady(success, message, elapsed, ratio);
}

void MainWindow::onCompressClicked()

    }

    startWork(false, inputFile, outputFile);

void MainWindow::startWork(bool isCompress, QString inPath, QString outPath)
{
    // 禁用按钮，防止重复点击
    ui->compressBtn->setEnabled(false);
    ui->decompressBtn->setEnabled(false);
    ui->selectFileBtn->setEnabled(false);
    ui->progressBar->setValue(0);
    ui->timeLabel->setText("压缩时间: -- s");
    ui->ratioLabel->setText("压缩率: -- %");
    ui->statusLabel->setText("状态: 工作中...");

    // 清理旧线程
    if (m_workerThread) {
        if (m_workerThread->isRunning()) {
            m_workerThread->quit();
            m_workerThread->wait();
        }
        delete m_workerThread;
    }

    m_workerThread = new QThread(this);
    CompressWorker *worker = new CompressWorker(isCompress, inPath, outPath);
    worker->moveToThread(m_workerThread);

    // 连接信号
    connect(m_workerThread, &QThread::started, worker, &CompressWorker::doWork);
    connect(worker, &CompressWorker::progressUpdated, this, &MainWindow::updateProgress);
    connect(worker, &CompressWorker::resultReady, this, &MainWindow::handleWorkFinished);
    connect(worker, &CompressWorker::resultReady, worker, &CompressWorker::deleteLater);
    connect(m_workerThread, &QThread::finished, m_workerThread, &QThread::deleteLater);

    m_workerThread->start();
}

void MainWindow::updateProgress(double value)
{
    ui->progressBar->setValue(static_cast<int>(value * 100));
}

void MainWindow::handleWorkFinished(bool success, QString message, double elapsedSeconds, double ratio)
{
    // 重新启用按钮
    ui->compressBtn->setEnabled(true);
    ui->decompressBtn->setEnabled(true);
    ui->selectFileBtn->setEnabled(true);
    ui->statusLabel->setText(QString("状态: %1").arg(message));

    if (success) {
        ui->timeLabel->setText(QString("耗时: %1 s").arg(elapsedSeconds, 0, 'f', 3));
        if (ratio > 0)
            ui->ratioLabel->setText(QString("压缩率: %1%").arg(ratio, 0, 'f', 1));
        else
            ui->ratioLabel->setText("压缩率: N/A");
        QMessageBox::information(this, "完成", message);
    } else {
        QMessageBox::critical(this, "错误", message);
        ui->progressBar->setValue(0);
    }
}

为什么会出现这些警告？
Qt Creator 默认会启用一些代码检查工具，当你打开 huffman.cpp 或 mainwindow.cpp 时，它们会分析你的 #include 语句。如果某个头文件没有被当前文件中的代码直接使用（例如你包含了 <algorithm> 但从未调用 std::sort），工具就会提醒你可以移除它，以保持代码简洁。

方案一：忽略（推荐，不影响任何功能）

为什么打开程序的同时还会弹出一个cmd
我们注意到用户问：为什么打开程序的同时还会弹出一个cmd？用户已经成功构建了Qt GUI程序，但双击exe运行时，除了GUI窗口外还会弹出一个黑色cmd窗口。这是典型的Qt程序在Windows上以控制台子系统链接时出现的行为。需要解释原因并提供解决方法：将项目从控制台子系统切换到窗口子系统。

这是因为你的程序在编译时被链接为了控制台子系统（console subsystem），而不是窗口子系统（windows subsystem）。当双击一个控制台子系统的 .exe 时，Windows 会自动创建一个命令行窗口（cmd）来容纳程序的输出（stdout/stderr），即使你的程序本身是图形界面。

🎯 解决方法：将项目改为窗口子系统
在 CMake 项目中（你当前使用的）
在 CMakeLists.txt 中添加以下一行，告诉链接器使用窗口子系统：

cmake
set(CMAKE_EXE_LINKER_FLAGS "${CMAKE_EXE_LINKER_FLAGS} -mwindows")
添加位置：放在 add_executable(...) 之后，target_link_libraries(...) 之前或之后均可。

完整示例（CMakeLists.txt 片段）
cmake
add_executable(HuffmanGUI main.cpp mainwindow.cpp huffman.cpp)
set(CMAKE_EXE_LINKER_FLAGS "${CMAKE_EXE_LINKER_FLAGS} -mwindows")
target_link_libraries(HuffmanGUI Qt6::Core Qt6::Widgets)
添加后，重新运行 CMake 配置并构建，生成的 .exe 再双击就不会弹出 cmd 窗口了。

📌 原理说明
控制台子系统：程序启动时自动分配控制台窗口，适合命令行工具。即使你关闭了控制台，GUI 窗口也会被关闭（因为进程终止）。

窗口子系统：程序直接启动 GUI 窗口，不创建控制台。这是纯 GUI 应用程序的标准行为。

-mwindows 是 MinGW 链接器标志，告诉链接器生成窗口子系统可执行文件。

🔁 如果你使用的是 qmake（.pro 文件）
在 .pro 文件中添加：

qmake
CONFIG += windows
然后重新构建。
